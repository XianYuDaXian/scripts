## X Grok 翻译按钮外置
在 X（原 Twitter）的信息流和帖子详情页外置官方 Grok 翻译入口，减少点击层级，方便快速查看帖子与回复的中文翻译。

### 功能特点

- **信息流直达**：在首页信息流的帖子操作区直接插入翻译按钮。
- **贴内翻译**：在帖子详情页里，可对主帖和回复分别触发翻译。
- **批量翻译**：主帖区域提供“翻译全部”，可连续处理当前可见内容。
- **结果内嵌展示**：翻译结果直接显示在原帖下方，不打断浏览流程。
- **沿用官方能力**：复用 X 官方 Grok 翻译接口，尽量保持原生体验。

### 安装说明

1. 确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 插件。
2. 下载并安装仓库中的 `X_Grok_Translate_External.js`。
3. 打开 [X](https://x.com/) 并登录账号，刷新页面后即可在帖子操作区看到“翻译”按钮。

### 使用说明

1. 在首页信息流中，点击任意帖子下方的“翻译”按钮即可查看中文翻译。
2. 在帖子详情页中，可对主帖和回复分别点击“翻译”。
3. 如需快速浏览整串讨论，可点击主帖区域的“翻译全部”。

## B站弹幕合并器
旨在提升 B 站视频观看体验。它允许你将其他 B 站视频的弹幕实时合并到当前播放的视频中，特别适合观看录播、多机位视频或需要同步其他投稿弹幕的场景。
## 功能特点

- **多源合并**：支持通过关键词搜索或直接输入 BV 号获取其他视频的弹幕。
- **精确匹配**：支持选择目标视频的具体分 P（Part）。
- **同步校准**：提供时间偏移（Offset）调整功能，确保弹幕与当前进度完美同步。
- **深度适配**：针对“时间弹幕”做了跳转适配，点击弹幕中的时间戳可正常跳转。
- **原生集成**：在 B 站视频播放页无缝添加“合并弹幕”按钮，操作简便。
